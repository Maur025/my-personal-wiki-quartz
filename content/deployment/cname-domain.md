Este tipo de registro me pareció mas interesante, se usa para asignar direcciones a un subdominio ejemplo `wiki.maur025.dev`, debemos asignar un redireccionamiento al subdominio `wiki`, por ejemplo podemos redireccionar lo que tenemos en un dominio o ip como el de github pages `<username>.github.io`, asi cuando visiten nuestro subdominio `wiki.maur025.dev` internamente resuelve el recurso con la ayuda de github pages utilizando las ip's dinámica de github pages.
