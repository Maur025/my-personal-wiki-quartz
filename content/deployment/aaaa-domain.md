Registro de dominio de tipo `AAAA`, sirve para asignar ip's v6 a un dominio, ejemplo `maur025.dev` se puede asignar 4 dominios que te provee el servicio donde lo estés agregando:

| IP v6 Servicio                          |
| --------------------------------------- |
| 3e33:072e:eef6:f20d:56bf:573b:2823:1941 |
| 008b:0988:7d54:afe9:bfad:7226:dd6d:01ac |
| 6ba6:1fae:2e8e:60fb:4fd9:c54b:73bc:f6d5 |
| 2841:c569:6a40:7026:fa50:10de:6334:43e0 |

Generalmente deben reemplazar a los que te da el proveedor de tu dominio.
