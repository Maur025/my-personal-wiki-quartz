Registro de dominio de tipo A, sirve para asignar ip's v4 a un dominio, ejemplo `maur025.dev` se puede asignar 4 dominios que te provee el servicio donde lo estés agregando:

| IP Servicio |
| ----------- |
| 10.20.0.2   |
| 10.20.0.3   |
| 10.20.0.4   |
| 10.20.0.5   |

Generalmente deben reemplazar a los que te da el proveedor de tu dominio.
